在科技的发展下，AI 逐渐进入普通人的日常生活，想必大家只要不是山顶洞人，都应该知道 AI 与自己的生活有多么密切相关。那么想必大家也应该对 AI 感兴趣，想学学 Vibe Coding 那么本期教程零基础，带你开始入门。

在正式开始用 AI 进行 Vibe Coding 之前，我们首先需要了解一些基本概念。

一、Vibe Coding 是什么

定义

Vibe Coding（氛围编程）是一种以自然语言描述意图、由 AI 生成并迭代代码的软件开发新范式。它的核心，是让开发者的精力从 “逐行敲代码” 转向 “表达需求与把控方向” 。

也就是说，程序员从手敲代码中解放出来，转换成指挥 AI 工作的角色。

二、Vibe Coding 的基础：大脑与手脚

顾名思义，我们要用 AI 进行代码开发，首先就需要有一个 AI 大模型来作为 “大脑” 。

但只有大脑还不够，我们还需要给它 “手脚” 。

传统的 AI 只是一个对话流：用户输入一段文字，AI 回复一段文字。

比如说，你想修改一个文件实现某种功能，单纯的对话式 AI 只能告诉你”该怎么去做”、“如何去做”、“该修改什么”——它给的是说明书，不是结果。

因此为了解决这种困境，就有了 Agent，让 AI 能够自主行动。

在”大脑—手脚”的比喻里，“手脚”指的就是能实际执行操作的工具和 AI 代理（Agent）。

于是整个结构可以拆成两半：

角色承担者职责
大脑AI 大模型理解意图、生成内容（思考）
手脚工具与 Agent执行具体操作：读写文件、运行命令、提交代码

而把大脑与手脚结合在一起，形成一个完整的 AI 编程工作流——我们就把它叫作”Vibe Coding”。

三、两种产品形态

了解了 Vibe Coding 是什么，我们就能正式开始介绍一些 AI 编程工具了。

因为 AI 的市场很大，所以各大厂商也开始逐渐推行起自己的编程工具——也就是把”模型的大脑”与”手脚”结合在一起的一个载体。

不过这个载体（也就是编程工具）也分一些类型，主要可以分为两大类：

  1. 有图形操作界面的（IDE / 云端 IDE）
  2. 直接命令行 CLI 的

它们本质其实没有区别，只是前者加了一个图形界面，更便于操作使用而已。判断一个工具好不好，看的是它背后的模型能力、装了什么手脚，而不是它的界面UI有多么花里胡哨。

四、国内主流工具盘点

接下来就让我推荐几个国内主流的AI编程工具。

4.1 IDE / 云端 IDE

TRAE

官网：https://www.trae.cn/（国内版） · https://www.trae.ai/（国际版）

  • 出品：字节跳动
  • 形态：独立 IDE，国内直连
  • 免费政策：手机号注册即可使用基础功能，免费、无时间限制
  • 亮点：界面全中文，开箱即用，不需要配置任何本地环境

Qoder CN（原通义灵码）

官网：https://qoder.com/

  • 出品：阿里云
  • 形态：支持 VS Code、JetBrains 及独立 IDE
  • 免费政策：个人社区版免费，含有限的补全次数与体验额度
  • 亮点：Java / Go / Spring 生态积累较深，适合服务端与大型项目

豆包 MarsCode

官网：https://www.marscode.com/

  • 出品：字节系
  • 形态：云端 IDE，浏览器打开即用
  • 免费政策：个人免费
  • 亮点：支持 100+ 语言，与飞书联动，适合边开会边改代码
品牌动态

豆包 MarsCode 的独立 IDE 已并入 Trae 生态：IDE 形态由 Trae 承接，插件版继续以 MarsCode 名义维护，marscode.com 首页现在也直接推广 Trae。也就是说，字节系这条产品线的”大脑+手脚”一体化方案，实际上已经统一到了上面介绍的 TRAE 门下。

4.2 IDE 插件

腾讯云 CodeBuddy

官网：https://www.codebuddy.ai/

  • 出品：腾讯云
  • 形态：IDE 插件
  • 免费政策：个人版免费
  • 亮点：支持 MCP 协议，与腾讯云、TAPD 深度集成，具备 Figma 转代码能力

文心快码（Comate）

官网：https://comate.baidu.com/

  • 出品：百度
  • 形态：IDE 插件
  • 免费政策：个人版免费
  • 亮点：支持 SPEC 规范驱动，覆盖 200+ 语言

华为云 CodeArts（码道）

官网：https://codearts.huaweicloud.com/

  • 出品：华为云
  • 形态：IDE 插件，支持 JetBrains 与 VS Code
  • 免费政策：公测期间面向开发者免费开放
  • 亮点：接入 GLM、DeepSeek 等多个模型，可自选”大脑”

CodeGeeX

官网：https://codegeex.cn/

  • 出品：智谱 AI
  • 形态：IDE 插件
  • 免费政策：个人用户完全免费
  • 亮点：支持 100+ 语言，提供补全、生成、跨语言翻译、单元测试、Agent 模式等能力

4.3 模型厂商直营：把”大脑”单独买

上面三家（TRAE、Qoder、CodeBuddy）走的是”开箱即用”路线；而模型厂商自己也在做另一件事——把”大脑”单独卖给你，手脚随便你自己配。

智谱 Z.ai

官网：https://z.ai/（国际） · https://open.bigmodel.cn/（国内开放平台）

  • 出品：智谱 AI
  • 形态：模型 API / CLI——GLM Coding Plan 套餐，可接入 Claude Code 等主流编程 CLI
  • 亮点：GLM 系列主打 agentic coding；上文提到的 CodeGeeX 插件同样出自智谱，可视为同一家的”轻量插件 + 重型模型”双线布局

Kimi（月之暗面）

官网：https://www.kimi.com/ · API 开放平台：https://platform.kimi.com/

  • 出品：月之暗面（Moonshot AI）
  • 形态：对话助手 + API 开放平台，另有开源 CLI 工具
  • 亮点：K3.1 Pro 主打复杂编程项目与智能体任务；Kimi K2 系列开源模型在 agentic coding 场景口碑不错

MiniMax

官网：https://www.minimax.cn/（国内） · https://www.minimax.io/（国际）

  • 出品：MiniMax
  • 形态：模型 API + MiniMax Agent
  • 亮点：M2.5 主打 agentic 编程；适合把”大脑”单独拎出来自由组合的玩家

五、关于”免费”的正确姿势

国内工具的一个普遍特点是：个人基础版免费是常态，但免费层通常在补全次数、Agent 调用次数或高级模型上有限制。

CAUTION

也就是说，仅仅只是有限制的”免费”。

如果真的跟菩萨一样全免费，那厂商也不用活了。

其实主流的编程工具和 IDE 远不止上面提到的这些。在各大厂商的相互竞争下，AI 编程工具这个市场都已快要饱和，因此各大厂商也开始卷一些免费额度，企图夺取市场份额。

所以，我们可以选择一些有免费额度的 IDE 去薅羊毛。不过各大厂商的免费政策随时会变，需要大家自行判断——也可以通过实时信息看一些博主的推荐，以及免费编程工具的额度情况来薅羊毛。

TIP

不过我这里还是要提一嘴：大家如果有能力的话，最好还是进行付费。

不仅是为了解除额度限制，更是为了用上更好的 AI 模型。如现在比较前沿的 Fable 5.1、GPT6 等，模型能力的提升对于编程编码能力的提升是十分显著的。

六、进阶玩法：大脑与手脚分离

这里进行补充和扩展一点。

在上面的“大脑—手脚”比喻中，我们就可以知道 Vibe Coding 的”大脑”和”手脚”是分离的。换而言之，也就是大脑和手脚是可以分开选的。同一个模型可以接不同的 IDE，不同的模型也可以接同一套 CLI。

故而也有一些开发者制作了单独的”手脚”工具，例如 DSH（DeepSeek Harness）——你只需要将这个手脚连接到云端大模型就能正常工作。

换而言之：

  • 大脑是主要的。大脑负责思考，没有大脑，整个 Vibe Coding 都是白谈。
  • 但手脚和大脑都是可以换的。你可以选择不同的 AI 大模型，再配上不同的手脚工具来进行 Vibe Coding 编程。

因此更高级一点的玩法是：你可以在市场和项目中自由寻找好用的 Agent 手脚，再配上自定义选择的云端大模型进行 API 调用大模型——这样你就获得了一个完全自定义 DIY 的好用的编程工具。

上面推荐的国内厂商编程工具，只是说把大脑和手脚结合了起来，并且给你一些免费额度，让用户开箱即用而已。

Vibe Coding 的门槛，比很多人想象的低。它不需要你写出多复杂的 Prompt，只要求你能把想要的东西说清楚——而这恰好是很多人已经很久没有练习过的能力。

所以别被”编程”两个字吓住。先挑一个免费额度的工具，今晚就让 AI 帮你写出第一个能跑起来的小脚本。
